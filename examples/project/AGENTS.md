# Example project

This tiny project demonstrates in-place AgentHub Core installation. Keep project facts here; dispatched role identity comes from `agents/<role>/AGENTS.md`, and this project's extra requirements for a role live in `agents/<role>/PROJECT.md`.

- Start work by reading `docs/`.
- Write new project decisions back into this project's `docs/`; do not leave them only in chat history.
- Change product code only in this project or in its isolated working copy.
