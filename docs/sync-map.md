# AgentHub ↔ AgentHubCore 对照表（sync-map）

- 用途：从私人主力版 AgentHub 往对外版 AgentHubCore 搬机制时的唯一清单。两边不自动同步，按需人工同步。
- 核对基线：2026-10-27（私人版的提交号只记在维护者本地，不进本仓）。每次同步后更新这一行的日期。
- 「收入」五档：**已有**（对外版已实现）/ **收入**（本版新做或改做）/ **部分**（只取思想或文案）/ **不收**（私人环境或依赖服务）/ **对外版先行**（私人版尚无，对外版先做）。
- 私人版一侧只用泛称描述机制，不写私人版的脚本名、文件路径、仓库名、项目名或账号。
- 维护规则：新机制先加一行再动手；状态变化改同一行；「不收」的行保留，防止重复讨论。
